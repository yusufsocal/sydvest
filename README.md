# SydVest
![Logo](/Users/studier/team-6/app/src/main/sydvest_logo-playstore.png)

Sydvest er en Android app som skal vise værdata til allmennheten. 
Appen er utviklet i faget "Software engineering med prosjektarbeid" ved Universitetet i Oslo
